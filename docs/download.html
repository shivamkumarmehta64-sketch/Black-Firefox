Step-by-step (mtube / ytube)

1
Download the zip

Click the download button above. The file is named like mtube-2.1.0-windows.zip.

2
Extract it

Right-click → Extract All. A good location is %LOCALAPPDATA%\mtube (i.e. C:\Users\you\AppData\Local\mtube).

3
Run the app (or create shortcuts)

Double-click mtube.exe. For a desktop and Start Menu shortcut, run install.cmd included in the zip.

4
That's it

No install wizard, no bloatware, no sign-up. If Windows asks about a certificate, see the FAQ.

Requirements

🪟 Windows 10 / 11

Both mtube and ytube are Windows apps.

🔌 WebView2 Runtime

Usually preinstalled on Windows 11. If missing, download it from Microsoft — it's free.

🧩 .NET Desktop Runtime

Windows 11 usually has it. If not, install the free .NET Desktop Runtime from Microsoft.
