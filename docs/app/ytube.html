Install on Windows

  1. 1Download the ytube-1.0.0-windows.zip from the releases page.
  2. 2Extract the zip anywhere (e.g. %LOCALAPPDATA%\ytube).
  3. 3Run ytube.exe, or run install.cmd to create Start Menu and desktop shortcuts.
  4. 4Need WebView2 + .NET details? See the install guide.
