mtube

LIVE …

An ad-free YouTube Music desktop client for Windows. Background playback, SponsorBlock, media keys and an audio-only mode — all in a lightweight WebView2 build. Free, forever.

⭐ ……🕐 …
⬇️ Download mtube View source ↗
🚫
Ad-free by default

Built-in SponsorBlock skips sponsors, intros and self-promo segments automatically.

▶️
Background playback

Music keeps playing even when the window is minimized — just like a real music app.

🎹
Media keys

Play, pause, next and previous right from your keyboard or media controls.

🎧
Audio-only mode

Save bandwidth and RAM by turning off video rendering entirely.

📺
Picture-in-Picture

Float the video on top of any other window while you keep working.

🪶
Lightweight

WebView2-based — no Electron, a tight RAM budget, fast startup.

Install on Windows

  1. 1Download the mtube-2.1.0-windows.zip from the releases page.
  2. 2Extract the zip anywhere (e.g. %LOCALAPPDATA%\mtube).
  3. 3Run mtube.exe, or run install.cmd to create Start Menu and desktop shortcuts.
  4. 4Need WebView2 + .NET details? See the install guide.
