Install on Windows

  1. 1Download blue-browser from the releases page.
  2. 2Extract the zip anywhere (e.g. %LOCALAPPDATA%\blue-browser).
  3. 3Run blue-browser.exe, or run install.cmd to add Start Menu and desktop shortcuts.
  4. 4Need WebView2 + .NET details? See the install guide.
